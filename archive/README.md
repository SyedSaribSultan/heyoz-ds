# archive

Nothing in here is wired to anything. It is kept because deleting it would lose the
reason it existed, not because it is expected to come back.

## `test-index.html` and `harness.mjs`

The standalone gate rig, and the template that generated it. Emitted by
`build/build.mjs` on every build until it was retired; the last generated copy is
the one here.

**What it did.** Inlined `reports/audit.json`, `dist/tokens.css` and
`dist/shadcn-bridge.css` into one file, so a reviewer could double-click it and see
every contrast, APCA, visibility, elevation and greyscale gate with no server, no
npm and no network. That property was the whole point and it is genuinely useful.

**Why it went.** It rendered the same dataset the showcase's `/verify` route now
renders, from the same file — and two renderings of one dataset is one more than can
be kept in step. The deciding argument was coverage rather than duplication: the rig
could only ever show the *token* gates, because it was generated by the token build.
Four of the checks that matter most live a layer above it:

| check | measures |
|---|---|
| `verify:contrast` | the 98 pairings the recipes **create** — deciding to put `content/primary` on `surface/critical` happens in a recipe, and `build/spec.mjs` cannot see it happened |
| `verify:motion` | that each component's spring family matches what it animates, and that no literal transform escapes `--oz-motion-spatial-scale` |
| `verify:borders` | that every stroke is an affordance or a state |
| `verify:classes` | that every class the recipes compose at runtime has a generated rule |

A verification artifact that structurally cannot show half the verification is worse
than none, because it looks complete.

**What it cost.** The double-click property. `/verify` needs
`npm run build && npm start` in `showcase/`.

**To bring it back.** Restore the `out('test/index.html', harnessHtml({…}))` call in
`build/build.mjs` — the note where it used to be says exactly where. `harnessHtml`
still takes `{ audit, shipped, tokensCss, bridgeCss }`, and `SHIPPED` is still
exported from `build/shipped.mjs`.
